# Agent Note：完成 Web 持久化文件接入

状态：已实现

[English](2026-08-20-web-durable-file-intake.md) | 中文

## 决策

Web 编辑器现在会将通用文件与草稿图片一同保留，直到主机准入。图片限制仍只作用于图片；非图片文件作为带 MIME 类型、规范 Base64 字节和显示名的 `file` 提示词部分发送。浏览器不会把这些字节保存到会话状态中。

会话渲染新增专用文件槽。它显示每个持久化引用的 MIME 元数据、已持久化的提取状态和可折叠的持久化预览。因此归档、重载或分叉后的会话会渲染主机记录的确切接入结果，无须再次解析。

## 影响

用户可见路径现已由同一对象贯通：拖放文件、持久化主机存储、模型提示词引用、会话卡片和会话恢复。Slash 命令仍拒绝通用文件，因为其命令 wire 只允许图片。

## 验证

已通过聚焦的附件、编辑器、会话运行时和客户端 fixture 测试。主机 TypeScript 通过；客户端类型检查仅到达与本改动无关的两个既有 `ui-trajectory` 穷尽返回错误。
