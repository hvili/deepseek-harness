# Agent Note：持久化文件接入预览与错误

状态：已实现

[English](2026-08-20-file-intake-preview-and-errors.md) | 中文

## 决策

主机提示词准入现在会在追加持久化 `file` 内容块前，提取有界 UTF-8 文本和 OOXML 文档预览。该内容块保存不可变附件引用、模型可见预览及带类型的提取结果，因此重载和分叉都能保留成功状态与诊断上下文，而不保留原始字节。

PDF 字节不会用不可靠的正则表达式抓取。在启用完整 PDF 引擎前，PDF 输入会记录 `PDF_TEXT_EXTRACTION_UNAVAILABLE`；损坏的 Office 压缩包、无效文本编码和不支持的类型分别得到稳定的结果。

## 影响

纯文本模型适配器在可用时接收提取内容，否则接收明确失败说明。下一步 UI 可直接从会话事件渲染状态和预览，无须重新运行解析器。

## 验证

已通过聚焦的文件接入、提示词准入及内容测试，并通过主机 TypeScript 构建。
