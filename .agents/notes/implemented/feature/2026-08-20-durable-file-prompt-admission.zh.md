# Agent Note：将通用文件纳入持久化提示词

状态：已实现

[English](2026-08-20-durable-file-prompt-admission.md) | 中文

## 决策

浏览器到主机的 `session.prompt` wire 现在除文本和图片外也接受通用 `file` 部分。主机解码其规范 Base64 载荷，经由 `AttachmentStore.saveFile` 存储，并记录一个只含不可变引用的 `file` 内容块。会话日志不会写入浏览器 Blob URL、源路径或原始字节。

纯文本适配器会把文件块投影为有界解析预览；在解析入口尚未提供预览时，它会输出明确的附件回退文本，包含已净化的显示名和 MIME 类型，而不会悄然丢弃用户材料。

## 影响

同一个持久对象现已连接上传准入、提示词历史、模型请求组装及后续会话恢复。文件解析及其 UI 状态由下一步接入；在此之前，回退文本会向模型明确说明解析器不可用。

## 验证

已通过聚焦的 API 架构/准入、DeepSeek 序列化测试及主机 TypeScript 构建。
